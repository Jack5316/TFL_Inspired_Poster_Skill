# Vector starters

Use these original, debranded SVGs when the user requests editable vector artwork, exact typography matters, or image generation cannot preserve mandatory text. Treat each as a compositional scaffold; replace all placeholder copy, colours, and subject geometry.

## Adaptation workflow

1. Copy the closest starter into the requested deliverable location; never modify the bundled starter in place during normal poster work.
2. Replace `HEADLINE`, `SUPPORT LINE`, and `CITY LINES • UNOFFICIAL CONCEPT` exactly. Keep visible text to the user's required wording.
3. Replace placeholder groups by ID: `subject`, `headline`, `support`, `identity`, and `photo-field` where present. Preserve the `viewBox` unless the user requests another ratio.
4. Use locally available generic fonts and include a sensible fallback stack. Convert text to paths only when the user requests production-lock artwork and the font licence permits it.
5. Change at least the subject, palette, and internal geometry. Do not deliver a starter with only words swapped.
6. Remove all fictional footer wording if the user wants a standalone illustration. Retain `UNOFFICIAL CONCEPT` when a poster names TfL or could be mistaken for live public information.
7. Render a preview and inspect it before delivery. Check text fit, safe margins, hierarchy, contrast, and absence of official marks.

## Safety boundary

The starters intentionally contain no official roundel, Tube map, controlled TfL typeface, station name, route colour system, or operational claim. Do not add those elements unless the user supplies authorized assets and explicitly requests their use.
